### Understand Within. Connect Beyond.

[Tiếng Việt](https://github.com/7mlabs-workspace) · **English**

7mlabs builds libraries and tools for applications that help people understand themselves and their connections. We focus on **verifiable calculation cores, structured results and clear documentation** so developers can integrate them into their own products.

[Website](https://7mlabs.com/en/) · [Ecosystem](https://7mlabs.com/en/structure/) · [Workspace repositories](https://github.com/orgs/7mlabs-workspace/repositories)

## SDK projects

| Project | Current scope | Source and documentation |
| --- | --- | --- |
| **Numerology** | Pythagorean numerology; a Rust core with Node.js, Python and .NET packages. **1.0.0** is released. | [Source](https://github.com/7mlabs-workspace/sdk-numerology) · [SDK overview](https://7mlabs.com/en/numerology/sdk/) · [Documentation & formulas](https://7mlabs.com/en/numerology/sdk/docs/1.0.0/overview/) |
| **Astro** | Charts, relationships, events and forecasts; JSON data, SVG and bindings sharing a Rust core. **1.1.2** is released. | [Source in its existing repository](https://github.com/7mLabs/sdk-astro) · [SDK overview](https://7mlabs.com/en/astro/sdk/) · [Documentation & formulas](https://7mlabs.com/en/astro/sdk/docs/1.1.2/overview/) |

**A new workspace, with the right repository for each project.** New 7mlabs SDK projects are organized under `7mlabs-workspace`. Astro continues to be maintained at `7mLabs/sdk-astro`; its source, releases and issue links still use that repository.

## Start integrating

1. Choose an SDK and review its calculation scope, school/method and supported configuration.
2. Follow the project's installation guides, examples and data contracts.
3. Check the SDK and third-party licenses before distributing your product.

The SDKs provide calculations and data. Presentation, narrative interpretation and user experience belong to the integrating application.
